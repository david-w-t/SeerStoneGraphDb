# Internal gRPC API for the External REST Proxy — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expose SeerStoneGraphDb's existing `graphdb_mgr` / `graphdb_instance` /
`graphdb_class` / `graphdb_attr` / `graphdb_rules` / `graphdb_language` /
`graphdb_project` / `graphdb_query` public API over gRPC via a new peer OTP
application, `graphdb_api`, for consumption by a non-Erlang REST proxy on the
same internal network.

**Architecture:** One gRPC service per owning worker module (8 services), each
a thin hand-written `_impl` module implementing a `grpcbox_plugin`-generated
behaviour and delegating straight to the real Erlang API — no new business
logic, only wire marshaling. Shared codecs (`graphdb_api_value` for AVP
`term()` values, `graphdb_api_error` for Erlang-reason → gRPC-status mapping)
are used by every service. `grpcbox` (verified: compiles clean on this
toolchain, pure-Erlang `gpb` codegen, no `protoc` binary needed) provides the
HTTP/2 transport and protobuf plumbing.

**Tech Stack:** Erlang/OTP 28.5, rebar3 3.27.0 (already on PATH per
`[rebar3-invocation]` memory — invoke as plain `./rebar3 ...`), `grpcbox
0.17.1`, `grpcbox_plugin` (rebar3 plugin, unpinned/latest — verified working),
`gpb` (transitive, pure Erlang).

**Spec:** `docs/designs/grpc-proxy-api-design.md` — read it before starting;
this plan does not repeat its reasoning, only its decisions.

## Global Constraints

- OTP 28.5 / rebar3 3.27.0 — the only toolchain this plan has been verified
  against. `./rebar3` (repo-local) — never `source ~/.bashrc &&` prefix.
- `grpcbox 0.17.1` pinned exact version in `rebar.config` (verified compiling
  clean; do not bump without re-verifying).
- Session over the wire is **always** a plain `int64 project_id` field,
  **never** a serialized `graphdb_project` session term. Every project-scoped
  handler reconstructs the session itself via
  `graphdb_project:open_session(ProjectId)` before delegating.
- AVP `term()` values cross the wire via the `Value` oneof
  (`str|i|d|b|term_binary|null_value`) defined once in `common.proto`, coded
  by `graphdb_api_value.erl`. AVP **updates** (which must distinguish
  "upsert" from "delete this attribute") use the separate `AVPUpdate`
  message (`attribute`, `value`, `delete` bool) — never conflate with the
  plain always-has-a-value `AVP` message used for reads.
- Every gRPC error response is built by `graphdb_api_error:to_status/1`: a
  curated gRPC status code **and** the raw Erlang reason,
  `base64(term_to_binary(Reason))`, in trailer key `x-erlang-reason-bin`.
  Never hand-roll a `{error, ...}` grpcbox tuple elsewhere.
- New-module header convention (see `apps/graphdb/src/graphdb_project.erl`
  for the template): copyright block (SeerStone Inc. 2008 + David W. Thomas
  2026), `Author: David W. Thomas`, `Created: 2026-07-08`, description,
  revision history, NYI/UEM macros, explicit `-export([...])` list. Every
  new `.erl` file in this plan follows it — shown once in Task 1, implied
  thereafter (each task's code block is the body; prepend the header before
  committing).
- No mocking `graphdb_mgr` / `graphdb_instance` / etc. in tests — every CT
  suite exercises the real Mnesia-backed stack via the isolated
  per-testcase bootstrap pattern from `apps/graphdb/test/graphdb_project_SUITE.erl`.
- `common_pb` (and any `*_pb` module with no `service` block) is **never**
  listed in a `service_protos` grpcbox config — only pb modules generated
  from a `.proto` file containing a `service { ... }` block go there.
- Generated `*_pb.erl`, `*_bhvr.erl`, `*_client.erl` files are build
  artifacts (regenerated by `./rebar3 grpc gen`) — `.gitignore`d, never
  hand-edited, never committed.
- **No proto3 `optional` scalar fields anywhere in this plan.** Cross-file
  `import` and message nesting were empirically verified against this
  toolchain (Task 2); proto3 explicit-presence `optional` was not, and its
  gpb map representation is an unverified assumption this plan will not
  build on. Every genuinely-optional integer field (e.g. an optional
  template nref) is a plain `int64` with **`0` as the sentinel for
  "unset"** — valid because every real nref in this system is a positive
  integer (nref allocation starts at 1; see `apps/graphdb/include/graphdb_nrefs.hrl`),
  so `0` can never collide with a real value. Every `_impl` module treats
  `0` as `undefined` when calling the arity that omits the optional arg.

**Path correction (discovered during Task 2, not obvious from a standalone
probe):** `grpcbox_plugin` resolves these paths relative to the *app's own
`BaseDir`* (`apps/graphdb_api/`) when it runs inside an umbrella project —
not relative to the workspace root. Paths written as
`"apps/graphdb_api/priv/protos"` double-path and fail to find the `.proto`
files. Use app-relative paths (`"priv/protos"`, `"src"`) as shown above —
this was not caught by this plan's earlier standalone `grpcbox_plugin`
probes because those ran in a single-app project at the workspace root,
where app-relative and root-relative paths are the same thing.

Update the `{relx, [{release, {seerstone, "0.1.0"}, [...]}, ...]}` app list.
It is currently `[nref, database, seerstone]`. Change to:

```erlang
{relx, [
    {release, {seerstone, "0.1.0"},
     [nref,
      database,
      seerstone,
      grpcbox,
      graphdb_api]},
    {sys_config, "config/sys.config"},
    {dev_mode, true},
    {include_erts, false}
]}.
```

This is the load-bearing ordering from the design's §6.1: `grpcbox` (which
auto-starts its configured listener from `sys.config` on its own app start)
is sequenced after `database` (which fully boots the graphdb stack,
bootstrap included) and before `graphdb_api` — so the port never opens
before the graph is ready, with no `start_phases` needed.

- [ ] **Step 1: Write `common.proto`**

```proto
syntax = "proto3";
package graphdb_api;

enum NodeKind {
  NODE_KIND_UNSPECIFIED = 0;
  CATEGORY = 1;
  ATTRIBUTE = 2;
  CLASS = 3;
  INSTANCE = 4;
  TEMPLATE = 5;
}

enum RelationshipKind {
  RELATIONSHIP_KIND_UNSPECIFIED = 0;
  TAXONOMY = 1;
  COMPOSITION = 2;
  CONNECTION = 3;
  INSTANTIATION = 4;
}

message NullValue {}

// A literal AVP value. `term_binary` is the erlang:term_to_binary/1
// fallback for anything that isn't a plain string/int/float/bool.
message Value {
  oneof kind {
    string    str         = 1;
    int64     i           = 2;
    double    d           = 3;
    bool      b           = 4;
    bytes     term_binary = 5;
    NullValue null_value  = 6;
  }
}

// Always carries a value — used for reads (Node.attribute_value_pairs,
// Relationship.avps) and for AVPs supplied at creation time.
message AVP {
  int64 attribute = 1;
  Value value = 2;
}

// Used only in update contexts, where "no value" (delete) must be
// distinguishable from "value is null_value" (a real declared-but-unbound
// upsert). See graphdb_mgr:update_node_avps/2's existing contract.
message AVPUpdate {
  int64 attribute = 1;
  Value value = 2;   // ignored when delete = true
  bool delete = 3;
}

message Node {
  int64 nref = 1;
  NodeKind kind = 2;
  repeated int64 parents = 3;
  repeated int64 classes = 4;
  repeated AVP attribute_value_pairs = 5;
}

message Relationship {
  int64 id = 1;
  RelationshipKind kind = 2;
  int64 source_nref = 3;
  int64 characterization = 4;
  int64 target_nref = 5;
  int64 reciprocal = 6;
  repeated AVP avps = 7;
}
```

- [ ] **Step 5: Write `apps/graphdb_api/src/graphdb_api_value.erl`**

```erlang
%%---------------------------------------------------------------------
%% Copyright (c) 2008 SeerStone, Inc.
%% Copyright (c) 2026 David W. Thomas
%% SPDX-License-Identifier: GPL-2.0-or-later
%%---------------------------------------------------------------------
%% Author: David W. Thomas
%% Created: 2026-07-08
%% Description: Codec between graphdb's AVP term() values and the
%%              common.proto Value/AVP/AVPUpdate wire messages (design
%%              §2.2). Also converts the Node/Relationship kind atoms
%%              to/from their proto enum integers.
%%
%%              Encoding rule: binaries and printable-unicode lists are
%%              `str`; integers are `i`; floats are `d`; booleans are
%%              `b`; `undefined` is `null_value`; everything else
%%              (opaque terms, non-printable lists, other atoms, tuples,
%%              maps) falls back to `term_binary` via
%%              erlang:term_to_binary/1, decoded back with the `safe`
%%              option to avoid unbounded atom-table growth from
%%              untrusted input.
%%---------------------------------------------------------------------
%% Revision History
%%---------------------------------------------------------------------
%% Rev PA1 Date: 2026-07-08 Author: David W. Thomas
%% Initial implementation: Value/AVP/AVPUpdate codec.
%%---------------------------------------------------------------------
-module(graphdb_api_value).

-revision('Revision: PA1 ').
-created('Date: 2026-07-08').
-created_by('david@davidwt.com').

-define(NYI(X), (begin
    io:format("*** NYI ~p ~p ~p~n",[?MODULE, ?LINE, X]),
    exit(nyi)
end)).
-define(UEM(F, X), (begin
    io:format("*** UEM ~p:~p ~p ~p~n",[?MODULE, F, ?LINE, X]),
    exit(uem)
end)).

-export([term_to_value/1, value_to_term/1,
         avp_to_pb/1, pb_to_avp/1,
         avp_update_to_term/1,
         node_kind_to_atom/1, atom_to_node_kind/1,
         relationship_kind_to_atom/1, atom_to_relationship_kind/1]).

%%-----------------------------------------------------------------------------
%% term_to_value(term()) -> common_pb:value()
%%-----------------------------------------------------------------------------
term_to_value(undefined) ->
    #{kind => {null_value, #{}}};
term_to_value(V) when is_binary(V) ->
    #{kind => {str, unicode:characters_to_list(V)}};
term_to_value(V) when is_integer(V) ->
    #{kind => {i, V}};
term_to_value(V) when is_float(V) ->
    #{kind => {d, V}};
term_to_value(V) when is_boolean(V) ->
    #{kind => {b, V}};
term_to_value(V) when is_list(V) ->
    case io_lib:printable_unicode_list(V) of
        true  -> #{kind => {str, V}};
        false -> #{kind => {term_binary, term_to_binary(V)}}
    end;
term_to_value(V) ->
    #{kind => {term_binary, term_to_binary(V)}}.

%%-----------------------------------------------------------------------------
%% value_to_term(common_pb:value()) -> term()
%%-----------------------------------------------------------------------------
value_to_term(#{kind := {str, Bin}}) ->
    unicode:characters_to_list(Bin);
value_to_term(#{kind := {i, I}}) ->
    I;
value_to_term(#{kind := {d, D}}) ->
    D;
value_to_term(#{kind := {b, B}}) ->
    B =:= true orelse B =:= 1;
value_to_term(#{kind := {term_binary, Bin}}) ->
    binary_to_term(Bin, [safe]);
value_to_term(#{kind := {null_value, _}}) ->
    undefined;
value_to_term(_) ->
    undefined.

%%-----------------------------------------------------------------------------
%% avp_to_pb(#{attribute := integer(), value := term()}) -> common_pb:avp()
%%-----------------------------------------------------------------------------
avp_to_pb(#{attribute := Attr, value := Value}) ->
    #{attribute => Attr, value => term_to_value(Value)}.

%%-----------------------------------------------------------------------------
%% pb_to_avp(common_pb:avp()) -> #{attribute := integer(), value := term()}
%%-----------------------------------------------------------------------------
pb_to_avp(#{attribute := Attr, value := Value}) ->
    #{attribute => Attr, value => value_to_term(Value)}.

%%-----------------------------------------------------------------------------
%% avp_update_to_term(common_pb:avp_update()) ->
%%     #{attribute := integer(), value => term()}
%%
%% Mirrors graphdb_mgr:update_node_avps/2's well-formedness contract: the
%% `value` key is present only for an upsert; a delete update carries no
%% `value` key at all.
%%-----------------------------------------------------------------------------
avp_update_to_term(#{attribute := Attr, delete := true}) ->
    #{attribute => Attr};
avp_update_to_term(#{attribute := Attr, value := Value} = Update) ->
    case maps:get(delete, Update, false) of
        true  -> #{attribute => Attr};
        false -> #{attribute => Attr, value => value_to_term(Value)}
    end.

%%-----------------------------------------------------------------------------
%% Node/Relationship kind <-> proto enum
%%-----------------------------------------------------------------------------
node_kind_to_atom('CATEGORY')  -> category;
node_kind_to_atom('ATTRIBUTE') -> attribute;
node_kind_to_atom('CLASS')     -> class;
node_kind_to_atom('INSTANCE')  -> instance;
node_kind_to_atom('TEMPLATE')  -> template.

%%---------------------------------------------------------------------
%% Author: David W. Thomas
%% Created: 2026-07-08
%% Description: Single chokepoint mapping an Erlang {error, Reason} (or
%%              bare Reason) into a grpcbox_stream:grpc_error_response().
%%              A curated table maps known reasons to the closest gRPC
%%              status code (design §5); anything uncurated falls back
%%              to INTERNAL. The raw Erlang reason always also survives,
%%              base64(term_to_binary(Reason))-encoded, in the
%%              x-erlang-reason-bin trailer, so no caller ever loses
%%              precision to the coarse status-code enum.
%%---------------------------------------------------------------------
%% Revision History
%%---------------------------------------------------------------------
%% Rev PA1 Date: 2026-07-08 Author: David W. Thomas
%% Initial implementation: curated status table + trailer passthrough.
%%---------------------------------------------------------------------
-module(graphdb_api_error).

-revision('Revision: PA1 ').
-created('Date: 2026-07-08').
-created_by('david@davidwt.com').

-define(NYI(X), (begin
    io:format("*** NYI ~p ~p ~p~n",[?MODULE, ?LINE, X]),
    exit(nyi)
end)).
-define(UEM(F, X), (begin
    io:format("*** UEM ~p:~p ~p ~p~n",[?MODULE, F, ?LINE, X]),
    exit(uem)
end)).

-export([to_status/1]).

%%-----------------------------------------------------------------------------
%% to_status({error, Reason} | Reason) -> grpcbox_stream:grpc_error_response()
%%-----------------------------------------------------------------------------
to_status({error, Reason}) ->
    build(Reason);
to_status(Reason) ->
    build(Reason).

build(Reason) ->
    Status = grpcbox_stream:code_to_status(code_for(Reason)),
    Message = unicode:characters_to_binary(io_lib:format("~p", [Reason])),
    TrailerVal = base64:encode(term_to_binary(Reason)),
    {error, {Status, Message},
     #{trailers => #{<<"x-erlang-reason-bin">> => TrailerVal}}}.

%%-----------------------------------------------------------------------------
%% code_for(Reason) -> 0..16  (standard gRPC status codes)
%%-----------------------------------------------------------------------------
code_for(not_found)                        -> 5;  % NOT_FOUND
code_for(not_a_project)                    -> 5;
code_for(relationship_not_found)           -> 5;
code_for(template_not_found)               -> 5;
code_for(invalid_session)                  -> 16; % UNAUTHENTICATED
code_for(category_nodes_are_immutable)     -> 3;  % INVALID_ARGUMENT
code_for(permanent_node_immutable)         -> 3;
code_for({instance_only_attribute, _})     -> 3;
code_for({invalid_direction, _})           -> 3;
code_for({class_not_instantiable, _})      -> 9;  % FAILED_PRECONDITION
code_for({ambiguous_relationship, _})      -> 9;
code_for({dangling_half_edge, _})          -> 13; % INTERNAL
code_for(not_implemented)                  -> 12; % UNIMPLEMENTED

%% {Transport, Host, Port, SslOpts} endpoint tuples, not positional
%% host/port arguments.

    Abs = filename:absname(Dir),
    IsAbsolute = (Abs =:= Dir),
    ContainsSentinel = (string:find(Dir, ?SCRATCH_SENTINEL) =/= nomatch),
    Leaf = filename:basename(Dir),
    HasPrefix = lists:prefix(?DIR_PREFIX, Leaf),
    IsAbsolute andalso ContainsSentinel andalso HasPrefix.

    case filelib:is_dir(Dir) of
        true ->
            {ok, Entries} = file:list_dir(Dir),
            lists:foreach(fun(E) ->
                Path = filename:join(Dir, E),
                case filelib:is_dir(Path) of
                    true  -> do_delete_dir(Path);
                    false -> file:delete(Path)
                end
            end, Entries),
            file:del_dir(Dir);
        false ->
            ok
    end.

    FwdAVPs = [graphdb_api_value:pb_to_avp(A) || A <- maps:get(fwd_avps, Op, [])],
    RevAVPs = [graphdb_api_value:pb_to_avp(A) || A <- maps:get(rev_avps, Op, [])],
    case maps:get(template, Op, 0) of
        0 ->
            {add_relationship, S, C, T, R};
        Template ->
            case {FwdAVPs, RevAVPs} of
                {[], []} -> {add_relationship, S, C, T, R, Template};
                _        -> {add_relationship, S, C, T, R, Template, {FwdAVPs, RevAVPs}}
            end
    end;

    {retire_node, Nref};
mutation_op_to_term(#{op := {unretire_node, #{nref := Nref}}}) ->
    {unretire_node, Nref};

    {update_node_avps, Nref, [graphdb_api_value:avp_update_to_term(U) || U <- Updates]};

    case maps:get(template, Op, 0) of
        0        -> {remove_relationship, S, C, T};
        Template -> {remove_relationship, S, C, T, Template}
    end;

    #{source := S, characterization := C, target := T, updates := Updates} = Op,
    Terms = [graphdb_api_value:avp_update_to_term(U) || U <- Updates],
    case maps:get(template, Op, 0) of
        0        -> {update_relationship, S, C, T, Terms};
        Template -> {update_relationship, S, C, T, Template, Terms}
    end;
mutation_op_to_term(#{op := {update_relationship_both, Op}}) ->

create_instance(Ctx, #{project_id := ProjId, name := Name, class_nref := ClassNref,
                        parent_nref := ParentNref}) ->
    with_session(ProjId, fun(Session) ->
        case graphdb_instance:create_instance(Session, Name, ClassNref, ParentNref) of
            {ok, Nref, Report} ->
                {ok, #{nref => Nref, report => graphdb_api_value:term_to_value(Report)}, Ctx};
            {error, Reason, _Report} ->
                graphdb_api_error:to_status(Reason);
            {error, _Reason} = Error ->
                graphdb_api_error:to_status(Error)
        end
    end).

add_relationship(Ctx, #{project_id := ProjId, source := S, characterization := C,
                         target := T, reciprocal := R} = Req) ->
    with_session(ProjId, fun(Session) ->
        FwdAVPs = [graphdb_api_value:pb_to_avp(A) || A <- maps:get(fwd_avps, Req, [])],
        RevAVPs = [graphdb_api_value:pb_to_avp(A) || A <- maps:get(rev_avps, Req, [])],
        Result = case maps:get(template, Req, 0) of
            0 ->
                graphdb_instance:add_relationship(Session, S, C, T, R);
            Template ->
                case {FwdAVPs, RevAVPs} of
                    {[], []} -> graphdb_instance:add_relationship(Session, S, C, T, R, Template);
                    _        -> graphdb_instance:add_relationship(Session, S, C, T, R, Template, {FwdAVPs, RevAVPs})
                end
        end,
        reply_ok_or_status(Result, Ctx)
    end).

remove_relationship(Ctx, #{project_id := ProjId, source := S, characterization := C,
                            target := T} = Req) ->
    with_session(ProjId, fun(Session) ->
        Result = case maps:get(template, Req, 0) of
            0        -> graphdb_instance:remove_relationship(Session, S, C, T);
            Template -> graphdb_instance:remove_relationship(Session, S, C, T, Template)
        end,
        reply_ok_or_status(Result, Ctx)
    end).

update_relationship(Ctx, #{project_id := ProjId, source := S, characterization := C,
                            target := T, updates := Updates} = Req) ->
    with_session(ProjId, fun(Session) ->
        Terms = [graphdb_api_value:avp_update_to_term(U) || U <- Updates],
        Result = case maps:get(template, Req, 0) of
            0        -> graphdb_instance:update_relationship(Session, S, C, T, Terms);
            Template -> graphdb_instance:update_relationship(Session, S, C, T, Template, Terms)
        end,
        reply_ok_or_status(Result, Ctx)
    end).

update_relationship_both(Ctx, #{project_id := ProjId, source := S, characterization := C,
                                 target := T, fwd_updates := Fwd, rev_updates := Rev} = Req) ->
    with_session(ProjId, fun(Session) ->
        FwdTerms = [graphdb_api_value:avp_update_to_term(U) || U <- Fwd],
        RevTerms = [graphdb_api_value:avp_update_to_term(U) || U <- Rev],
        Result = case maps:get(template, Req, 0) of
            0        -> graphdb_instance:update_relationship_both(Session, S, C, T, {FwdTerms, RevTerms});
            Template -> graphdb_instance:update_relationship_both(Session, S, C, T, Template, {FwdTerms, RevTerms})
        end,
        reply_ok_or_status(Result, Ctx)
    end).

add_class_membership(Ctx, #{project_id := ProjId, instance_nref := InstNref,
                             class_nref := ClassNref}) ->
    with_session(ProjId, fun(Session) ->
        Result = graphdb_instance:add_class_membership(Session, InstNref, ClassNref),
        reply_ok_or_status(Result, Ctx)
    end).

get_instance(Ctx, #{nref := Nref}) ->
    case graphdb_instance:get_instance(Nref) of
        {ok, Node} -> {ok, #{node => graphdb_api_value:node_to_pb(Node)}, Ctx};
        Error      -> graphdb_api_error:to_status(Error)
    end.

children(Ctx, #{nref := Nref}) ->
    case graphdb_instance:children(Nref) of
        {ok, Nodes} -> {ok, #{children => [graphdb_api_value:node_to_pb(N) || N <- Nodes]}, Ctx};
        Error       -> graphdb_api_error:to_status(Error)
    end.

compositional_ancestors(Ctx, #{nref := Nref}) ->
    case graphdb_instance:compositional_ancestors(Nref) of
        {ok, Nodes} -> {ok, #{ancestors => [graphdb_api_value:node_to_pb(N) || N <- Nodes]}, Ctx};
        Error       -> graphdb_api_error:to_status(Error)
    end.

class_of(Ctx, #{instance_nref := Nref}) ->
    case graphdb_instance:class_of(Nref) of
        {ok, ClassNref} -> {ok, #{class_nref => ClassNref}, Ctx};
        Error           -> graphdb_api_error:to_status(Error)
    end.

class_memberships(Ctx, #{instance_nref := Nref}) ->
    case graphdb_instance:class_memberships(Nref) of
        {ok, Classes} -> {ok, #{classes => Classes}, Ctx};
        Error         -> graphdb_api_error:to_status(Error)
    end.

resolve_value(Ctx, #{instance_nref := Nref, attr_nref := AttrNref}) ->
    case graphdb_instance:resolve_value(Nref, AttrNref) of
        {ok, Value, Source} ->
            {ok, #{value => graphdb_api_value:term_to_value(Value),
                   source => source_to_pb(Source)}, Ctx};
        Error ->
            graphdb_api_error:to_status(Error)
    end.

%%-----------------------------------------------------------------------------
%% Internal
%%-----------------------------------------------------------------------------
with_session(ProjId, Fun) ->
    case graphdb_project:open_session(ProjId) of
        {ok, Session}    -> Fun(Session);
        {error, _} = Err -> graphdb_api_error:to_status(Err)
    end.

reply_ok_or_status(ok, Ctx)      -> {ok, #{}, Ctx};
reply_ok_or_status(Error, _Ctx)  -> graphdb_api_error:to_status(Error).

source_to_pb(local)                 -> #{kind => {local, true}};
source_to_pb({class, Nref})         -> #{kind => {class_nref, Nref}};
source_to_pb({compositional, Nref}) -> #{kind => {compositional_nref, Nref}};
source_to_pb({connected, Nref})     -> #{kind => {connected_nref, Nref}}.

-revision('Revision: PA1 ').

-created_by('david@davidwt.com').

-export([create_composition_rule/2, create_connection_rule/2, get_rule/2,
         rules_for_class/2, composition_rules_for_class/2,
         connection_rules_for_class/2, effective_rules_for_class/2,
         effective_connection_rules/2, list_rules/2]).

-define(SCOPE, environment).

create_composition_rule(Ctx, #{name := Name, parent_class := ParentClass,
                                child_class := ChildClass, mode := Mode,
                                multiplicity := Mult} = Req) ->
    ModeAtom = mode_to_atom(Mode),
    MultTerm = multiplicity_to_term(Mult),
    Template = maps:get(template_nref, Req, 0),
    NamePattern = maps:get(name_pattern, Req, ""),
    Opts = case NamePattern of
        "" -> #{};
        P  -> #{name_pattern => P}
    end,
    Result = case Template of
        0 -> graphdb_rules:create_composition_rule(?SCOPE, Name, ParentClass, ChildClass, ModeAtom, MultTerm);
        T -> graphdb_rules:create_composition_rule(?SCOPE, Name, ParentClass, ChildClass, ModeAtom, MultTerm, T, Opts)
    end,
    case Result of
        {ok, RuleNref} -> {ok, #{rule_nref => RuleNref}, Ctx};
        Error          -> graphdb_api_error:to_status(Error)
    end.

create_connection_rule(Ctx, #{name := Name, source_class := SourceClass,
                               characterization := Char, reciprocal := Recip,
                               target_class := TargetClass, mode := Mode,
                               multiplicity := Mult} = Req) ->
    ModeAtom = mode_to_atom(Mode),
    MultTerm = multiplicity_to_term(Mult),
    Result = case maps:get(template_nref, Req, 0) of
        0 -> graphdb_rules:create_connection_rule(?SCOPE, Name, SourceClass, Char, Recip, TargetClass, ModeAtom, MultTerm);
        T -> graphdb_rules:create_connection_rule(?SCOPE, Name, SourceClass, Char, Recip, TargetClass, ModeAtom, MultTerm, T)
    end,
    case Result of
        {ok, RuleNref} -> {ok, #{rule_nref => RuleNref}, Ctx};
        Error          -> graphdb_api_error:to_status(Error)
    end.

get_rule(Ctx, #{rule_nref := RuleNref}) ->
    case graphdb_rules:get_rule(?SCOPE, RuleNref) of
        {ok, Node} -> {ok, #{node => graphdb_api_value:node_to_pb(Node)}, Ctx};
        Error      -> graphdb_api_error:to_status(Error)
    end.

rules_for_class(Ctx, #{class_nref := ClassNref}) ->
    opaque_reply(graphdb_rules:rules_for_class(?SCOPE, ClassNref), rules, Ctx).

composition_rules_for_class(Ctx, #{class_nref := ClassNref}) ->
    opaque_reply(graphdb_rules:composition_rules_for_class(?SCOPE, ClassNref), rules, Ctx).

connection_rules_for_class(Ctx, #{class_nref := ClassNref}) ->
    opaque_reply(graphdb_rules:connection_rules_for_class(?SCOPE, ClassNref), rules, Ctx).

effective_rules_for_class(Ctx, #{class_nref := ClassNref}) ->
    opaque_reply(graphdb_rules:effective_rules_for_class(?SCOPE, ClassNref), rules, Ctx).

effective_connection_rules(Ctx, #{class_nref := ClassNref}) ->
    opaque_reply(graphdb_rules:effective_connection_rules(?SCOPE, ClassNref), rules, Ctx).

list_rules(Ctx, _Req) ->
    case graphdb_rules:list_rules(?SCOPE) of
        {ok, Nodes} -> {ok, #{rules => [graphdb_api_value:node_to_pb(N) || N <- Nodes]}, Ctx};
        Error       -> graphdb_api_error:to_status(Error)
    end.

%%-----------------------------------------------------------------------------
%% Internal
%%-----------------------------------------------------------------------------
opaque_reply({ok, Term}, Key, Ctx) ->
    {ok, #{Key => graphdb_api_value:term_to_value(Term)}, Ctx};
opaque_reply(Error, _Key, _Ctx) ->
    graphdb_api_error:to_status(Error).

mode_to_atom('MANDATORY') -> mandatory;
mode_to_atom('AUTO')      -> auto;
mode_to_atom('PROPOSE')   -> propose.

multiplicity_to_term(#{unbounded := true, min := Min}) ->
    {Min, unbounded};
multiplicity_to_term(#{min := Min, max := Max}) ->
    {Min, Max}.
```

**Verified signatures** (re-read `handle_call` clauses in

`register_dialect/3 -> {ok, Nref} | {error, already_registered | term()}`;
`lookup_language_nref/1 -> {ok, Nref} | {error, not_found}`; `set_labels/3`
takes a plain **AVP list** (`#{attribute => AttrNref, value => Label}`,
same shape as everywhere else) and returns `ok | {error,

return, not `{ok, _}`) whose internal structure is opaque to callers
outside this module — `resolve_label/4` just consumes whatever
`make_chain/1` produced. **`Chain` crosses the wire as an opaque `Value`
round-tripped by the client** (`MakeChain` returns it, `ResolveLabel` takes
it back unchanged) — the correct contract for a continuation-style token,
not a cop-out.

**Scope decision:** `set_labels/3` hardcodes the overlay table to
`environment` internally already (`overlay_table_name(Code, environment)`);
project-scoped label overlays are `TASKS.md` future work (SP2+). **v1
hardcodes `Scope = environment`** for `ResolveLabel` too, no scope field on
the wire — same rationale as Task 9's `RulesService` scope decision.

    case graphdb_language:register_language(Code, Name) of
        {ok, Nref} -> {ok, #{nref => Nref}, Ctx};
        Error      -> graphdb_api_error:to_status(Error)
    end.

register_dialect(Ctx, #{code := Code, name := Name, base_code := BaseCode}) ->
    case graphdb_language:register_dialect(Code, Name, BaseCode) of
        {ok, Nref} -> {ok, #{nref => Nref}, Ctx};
        Error      -> graphdb_api_error:to_status(Error)
    end.

lookup_language_nref(Ctx, #{code := Code}) ->
    case graphdb_language:lookup_language_nref(Code) of
        {ok, Nref} -> {ok, #{nref => Nref}, Ctx};
        Error      -> graphdb_api_error:to_status(Error)
    end.

set_labels(Ctx, #{nref := Nref, code := Code, labels := Labels}) ->
    Terms = [graphdb_api_value:pb_to_avp(A) || A <- Labels],
    case graphdb_language:set_labels(Nref, Code, Terms) of
        ok    -> {ok, #{}, Ctx};
        Error -> graphdb_api_error:to_status(Error)
    end.

make_chain(Ctx, #{codes := Codes}) ->
    Chain = graphdb_language:make_chain(Codes),
    {ok, #{chain => graphdb_api_value:term_to_value(Chain)}, Ctx}.

resolve_label(Ctx, #{nref := Nref, attr_nref := AttrNref, chain := ChainPb}) ->
    Chain = graphdb_api_value:value_to_term(ChainPb),
    case graphdb_language:resolve_label(Nref, AttrNref, Chain, ?SCOPE) of
        {ok, Label} -> {ok, #{label => graphdb_api_value:term_to_value(Label)}, Ctx};
        Error       -> graphdb_api_error:to_status(Error)
    end.

**Files:**

- Produces: nothing new consumed by later tasks (leaf service).

**Scope reminder (design §3.1):** only `find_path/3` ships in v1.
`execute_query/1,2`, `resume/2`, and general query-record marshaling are
explicitly deferred — no text DSL or query-AST proto exists yet, and
inventing one now would be designing ahead of the Erlang API.

**Verified return shape** (traced `find_path/3` → `execute_query/1` →
`dispatch/2` → `bfs/8` in `apps/graphdb/src/graphdb_query.erl:624-648`):
`find_path/3` resolves to exactly one of `{ok, no_path}` (frontier
exhausted, no path exists), `{ok, Path}` (`Path :: [integer()]`, a
complete path found), or `{partial, BestSoFar, Cont}` (`max_depth`
exhausted before finding the target; `Cont :: #cont_path{}` is a
resume-continuation token). **Because `resume/2` is out of scope for v1
(design §3.1), `Cont` is discarded, not exposed** — surfacing an opaque
token with no RPC that can consume it would be dead API surface. The
`partial` case reports `found = false` with `path` set to the
best-effort prefix, identical in shape to the `no_path` case's empty-path
report but with a non-empty prefix when one exists.

  bool found = 1;          // true iff a complete path was found
  repeated int64 path = 2; // the path (found=true), or the best-effort
